# Vanarmory

FF11 の装備セットを、狙いたいステータスから組むツール。

ジョブと目標値 (例: 侍、ストアTP 50、ヘイスト 25、被ダメージ -40) を入れると、それを満たす装備セットの候補を並べる。部位を固定して残りだけを探すこともできる。

ブラウザで開くだけで動く。インストールやサーバーは要らない。

## 使い方

`web/index.html` をブラウザで開く。

1. ジョブ、サポートジョブ、キャラクター、使う装備の設定を選ぶ。サポのレベルは、キャラクターのマスターレベルから自動で入る (手で変えることもできる)。装備以外で得る分 (ジョブ特性・ギフト・メリポ・食事) は、その下の「装備以外」で入・切できる
2. 「＋ ステータスを追加」から、分類 → ステータスの順に選んで目標値を入れる。上の欄に名前や略称 (STP、DA、WSダメ、カット など) を打って探すこともできる。被ダメージのように小さいほど良いものは負の値で入れる。目標の枠の 2 行目に、装備以外で得ている分・上限・(振り数なら) 必要なストアTP が出る。ロールや歌などの支援効果で得る分は、枠の右下の「＋ 支援など」で足せる
3. 「選び方」を選ぶ
   - **少ない部位で満たす** … 目標をなるべく少ない部位で満たし、残りを自由枠として空ける
   - **満たしたうえで伸ばす** … 目標を満たしたうえで、指定したステータスが最大になるセットを出す
4. 「セットを探す」を押す

候補のいちばん上に「見比べ」の表が出る。候補を 1 行ずつ並べ、目標・伸ばすステータス・振り数の値と、候補 1 と違う部位を出す。列ごとにいちばん良い値は緑、目標に届かない値は赤。行を押すとその候補へ移動する。

候補は、ゲーム内の装備欄と同じ 4×4 の並びで出る。

- 上の札: 目標ごとの達成 (✓ 届いた / ✕ 届かない。届かないものだけ、棒と不足の量が出る)。↑ は伸ばすステータス
- 装備欄: 左に HP・MP・STR〜CHR (素の値 + 増える分)。候補 1 と違うマスは、左に橙の線が付く
- 攻撃・命中 (遠隔の武器があれば飛攻・飛命も) と TP。攻撃と命中は、メイン (飛攻・飛命はレンジか矢弾) の武器を固定していると、ゲーム内の値として計算する
- 合計ステータス: 目標と伸ばすステータスは緑。スキル・ペット・その他・条件つき・特殊効果は、目標が無ければ「そのほか」に畳む (開け閉めはすべての候補でそろう)

マスを押すと装備の説明と「固定」「除外」が出る。固定するとその部位はその装備のままで残りを探し直せる。持っていない装備は除外すれば候補から消える。左の「固定する装備」のマスを押して、名前から固定することもできる。条件は次に開いたときも残る。

### 強化 (オーグメント) の設定

「設定」の画面で、強化をどこまで進めているかを選ぶ。

- **オデシー装備**: 系統 (アトーンメント 3・4 のボス) ごとに、いまのランクを選ぶ。国光はイケンガ、月桂の太刀はグレティに入る。アトーンメント 1・2 の装備 (ヘスペリデ、アクロンティカなど) は、段階 1・2 ごとに選ぶ
- **ランクを選べない強化** (リンバス装備、デュナミス〔D〕の首装備、ギアスフェットの装束、免罪装備、ウォンテッド装備の HQ、メナスインスペクターの装備): 「コンテンツごとの装備」の行にある「強化」を押して切り替える。「強化 最大」なら上限まで強化した状態、「強化 なし」なら強化していない状態を使う
- 高名値の首装備 (モンストロス・プレッジ) は、いつも強化した状態を使う
- 武器の強化 (レリックなどのランク 15、Oboro のジョブ別の武器、リンバスの武器、ニビル武器など) は、固定するときに強化した状態かどうかを選ぶ

### 得TP と振り数

武器を固定すると、候補ごとに「近接の TP」「遠隔の TP」が出る: 1 ヒットの得TP、WS後TP から TP1000 までの振り数、平均の攻撃ラウンド数、あと 1 振り減らすのに要るストアTP、TP の積み上がり。

- 「WS後TP」の欄に、WS を撃った直後の TP を近接と遠隔で別々に入れる。数値で入れるか、WS の段数から計算するかを選べる。欄は、武器を固定している側と、振り数を目標にした側だけ出る
- 目標に「近接の振り数」「遠隔の振り数」を選べる (「＋ ステータスを追加」の「TP・攻撃間隔」)。固定した武器の隔と WS後TP から必要なストアTP を計算し、ストアTP の目標として探す

### 設定 (キャラクター・ジョブの育成・装備の範囲)

`web/settings.html` (各画面の上の「設定」) で決める。検索の条件とは別に保存される。2 段階になっている。

1. **キャラクター** (画面の上)。自由に名前を付けて複数持てる。ジョブの育成と、装備の範囲の設定を、キャラクターごとに持つ
2. **装備の範囲の設定** (「装備の範囲」タブ)。キャラクターごとに「メイン」「復帰直後」のように複数持てる。別のキャラクターへコピーもできる

「ジョブの育成」タブには、ジョブごとに次を入れる。「セットを組む」でジョブを選ぶと、そのジョブの値が使われる。

- 使ったジョブポイントの合計 (0〜2100)。そこまでに覚えるギフトを数える
- マスターレベル。サポートジョブのレベルが決まる (49 + マスターレベル ÷ 5、最大 59)
- ジョブ別のメリポを最大まで振っているか

「装備の範囲」タブでは、候補に使う装備を決める。

- ジョブ専用装束 (AF・レリック・エンピリアン) は、+いくつまで使うか
- オデシー装備は、系統 (ニャメ・サクパタ・イケンガ・ムパカ・アグゥ・ブンジ) ごとの RP のランク (5 刻み)
- コンテンツごとの装備は、使う・使わないと、段階があるものはどこまでか。上位ミッションBF はバトルフィールドごと、エスカ・醴泉島は NM の強さ (T1〜最上位) まで選べる
- 候補から「除外」した装備も、設定ごとに保存される
- 名前の後ろのリンクマークから、FF11用語辞典のそのコンテンツのページを開ける

どのコンテンツの一覧にも無い装備 (店売り・競売・クエスト報酬など) は常に使う。

「オーグメントの手入力」タブでは、ランダムで付くオーグメント (ソーティの耳装備など) を、ゲーム内の表記 (「STR+8 DEX+8 命中+12」) で装備ごとに入力する。キャラクターごとに保存され、その装備の性能に上乗せされる。「セットを組む」で候補のマスを押したところからも入力できる。種族 (素のステータスの計算に使う) と共通のメリポは、「ジョブの育成」タブで入れる。

### 決まりごと

- 武器 (メイン・サブ・レンジ) は固定したものだけを使う。自動では選ばない。レンジを固定したときは矢弾も自動で選ばない
- 耳・指に同じ装備を 2 つ着けることはしない
- 同時に持てない装備は、1 つのセットに 1 つだけ使う。報酬リング (プロマシア・アトルガン・アドゥリン・蝕世のエンブリオの、どれか 1 つを選ぶ指輪) は、同じ系統から 1 つまで (フィックリングとレコリングは一緒に出ない)。系統が違えば一緒に使う。組は `data/exclusive.json`
- 「両手両脚両足装備不可」のように他の部位を塞ぐ装備は、固定したときだけ使う
- メイン・頭・胴・両手・両脚・両足は IL119 の装備だけを扱う。それ以外 (アクセサリなど) はレベルを問わない。「ステータスを追加」に並ぶのも、この範囲の装備にあるステータスだけ。合成・錬成・釣り・採集用の装備は載せていない
- アンバスケードのマント (ジョブマント) は、アイテム 5 種 (糸・金粉・染料・水油・樹脂) につき 1 項目ずつ、最大まで強化した値で付ける。持っているマントは、設定の「ジョブマント」タブで、ジョブと構成を選び、名前を付けて登録する (キャラクターごと)。「セットを組む」で背のマスを押したところからも、構成を選び直して登録できる。自動で選ぶときは、そのジョブに登録したマントの中から選ぶ。登録が無いときと、登録したマントでは目標に届かないときは、目標に合う構成を作る (作ったときは、結果の上に知らせが出る)
- 説明文に載らないオーグメントのうち、値が決まっているものは強化した状態を別の候補として持つ: オデシー装備 (RP のランク別)、レリック・ミシック・エンピリアン・イオニック・エルゴンの武器 (ランク 15)、デュナミス〔D〕の首装備 (品質ごとの上限のランク。自動で選ぶときは、この状態だけを使う)、リンバス装備 (ホープ・トラスト・ブレーブ・ジャスト・慈悲の各装束、アスプロピアス・メランリング・アスプロマント・メランマント、アウゲーなどの武器のランク 30)、シェオル・ジャイアのほかの装備 (ヘスペリデ、エピタフサシェ、アクロンティカ、グレティ装束など 19 点のランク 5〜30 (5 刻み)。設定の「オデシー装備」で、アトーンメント 1・2 は段階ごと、アトーンメント 3 は系統ごとにいまのランクを選ぶ)、Oboro のジョブ別の武器 (ミノス、クロノスなど 22 点のランク 15)、ギアスフェットの装備 (エスカイト・デスペア・那伽・ローハイド・パスーア・サイクロス・ヴァニヤの各装束、ニビル武器、エスカ-ル・オンのジョブ専用武器の計 73 点のランク 15。方針 A〜D を別の候補として持つ)、ウォンテッド装備の HQ (108 点のランク 15。自動で選ぶときは、強化した状態の中から選ぶ)、インベンター・ワークス (メナスインスペクター I・II の武器と防具 61 点のランク 15、方針 A〜C)、モンストロス・プレッジ (高名値の首装備 4 点のランク 15、方針 A〜C)、IL119 の免罪装備 (ルストラ・スヴレン・アゴシ・羅王・アポジ・カマイン・エミチョ・龍王・アデマ・アマリク・ケカスのランク 15。方針 A〜D を別の候補として持ち、自動で選ぶときは、この状態の中から選ぶ)
- 「右耳:ダブルアタック+8%」のように右耳専用の性能を持つ耳装備は、右耳 (耳2) にだけ着ける
- ジョブ専用装束 (AF・レリック・エンピリアン) は、設定で使ってよい中でいちばん上の段階だけを候補にする (+3 まで使えるなら +2 は出さない)。下の段階を使いたいときは固定する
- 目標に届かないときは、空いた部位も埋めて、いちばん目標に近い組み合わせを出す
- 得TP は、隔から決まる基本の値にストアTP を掛けて出す (式と出典は `web/tp.js`)。ヘイストやスナップショットは関わらない
  - 「n 振り」は、WS後TP から n 回当てて TP1000 に届く回数 (ダブルアタックなどは入れない)。「平均ラウンド」は、ダブルアタック・トリプルアタック・クワッドアタックを入れた目安 (命中 100% として)
  - 二刀流 (メインとサブに武器) は (メイン + サブの隔) × (1 − 二刀流) の半分、格闘は (480 + 武器の隔 − マーシャルアーツ) の半分を、1 発ぶんの隔にする。遠隔はレンジと矢弾の隔を足す (近接と同じ式で計算する)
  - WS の段数から計算するときは、初段が通常の 1 ヒットぶん、2 段目以降は 1 段につき 10 (ストアTP は掛けない)。全段命中として数え、二刀流・格闘の左手ぶんの加算は入れない
  - 振り数を目標にしたときの二刀流・マーシャルアーツは、装備以外の分と固定した装備の分で計算する (自動で選ばれた装備に二刀流が付くと、得TP が減って振り数が変わることがある。候補の「近接の TP」で確かめる)
- 潜在能力など条件つきの効果は数えない。ユニティランクで変わる値は幅の中間で数える
- セット効果 (コンビネーション) のうち数値で表せるものは、着けた部位数に応じて合計に入れる
- 装備以外の分として、ジョブ特性・ギフト・メリポ・食事を合計に入れられる。サポートジョブの特性は、サポのレベルで覚えている段階まで数え、メインと同じ特性は高いほうだけを使う。食事の「+10% (最大100)」のような効果は上限の値で数える
- 上限のあるステータス (ヘイスト 26%、被ダメージ -50% など) は、目標が上限を超えていれば上限に合わせ、「伸ばす」に選んだときは上限で止める。上限の値と出典は `data/caps.json`
- 候補は、いちばん良いと保証された組み合わせから順に出る。2 番目以降は、前の候補と 2 つ以上の装備が違うものを出す。計算が長引いたとき (全体で 15 秒) は打ち切り、そのときは結果の上に注意が出る。計算は別のスレッドで動くので、その間も画面は操作できる (見つかった候補の数が「計算中… 候補 3 件」のように出る)。計算中に条件を変えたときは、出た結果が前の条件のものだと知らせる

`web/search.html` は、ステータスから装備を 1 つずつ探す画面。

## 構成

| 場所 | 内容 |
| --- | --- |
| `web/theme.css` | 3 つの画面で共通の色とヘッダー。OS の設定に合わせて、明るい画面 (白 + 青) と暗い画面 (濃紺 + 金) を切り替える |
| `web/index.html`, `web/builder.js`, `web/builder.css` | セットを組む画面 |
| `web/solver-ilp.js` | セットを探す計算。整数計画法のソルバー HiGHS に解かせる。HiGHS は Web Worker (別のスレッド) で動かす |
| `web/solver.js` | 候補の装備の絞り込みと合計の計算。HiGHS を読み込めないときの予備の計算もここ (`index.html?dp=1` で開くと、こちらで計算する) |
| `web/vendor/` | HiGHS (highs 1.16.0、MIT ライセンス)。`highs-wasm.js` は、`file://` でも読み込めるように `highs.wasm` をスクリプトにしたもの |
| `web/settings.html`, `web/settings.js`, `web/settings.css` | 使う装備の設定の画面 |
| `web/profiles.js` | キャラクターと設定の保存、装備を使ってよいかの判定 |
| `web/basestats.js` | 素のステータスと、攻撃・命中の計算 |
| `web/tp.js` | 得TP と振り数の計算 |
| `web/augment.js` | 手入力のオーグメントを装備の性能に上乗せする |
| `web/parse.js` | 装備の説明文 (と手入力のオーグメント) をステータスに分解する |
| `web/search.html`, `web/search-page.js` | 装備を探す画面 |
| `web/search.js` | ステータスの候補出し・分類と、装備の絞り込み |
| `web/data.js` | 装備データ。`tools/build-data.mjs` が作る |
| `data/augments.json` | 説明文に載らないオーグメント (オデシー装備の RP、武器の強化、首装備) と、ソーティの耳装備に付く値の幅 |
| `data/base.json` | 種族・ジョブごとの成長の表 (素のステータスの計算用) |
| `data/combat.json` | 武器の種類とジョブごとのスキル上限 (攻撃・命中の計算用) |
| `data/capes.json` | アンバスケードのマントと付与できる項目 |
| `data/sets.json` | ジョブ専用装束 (AF・レリック・エンピリアン) の見分け方 |
| `data/setbonus.json` | セット効果の値 |
| `data/exclusive.json` | 同時に持てない装備の組 (報酬リング) |
| `data/jobs.json` | ジョブ特性・ギフト (必要ジョブポイントつき)・メリポで得る値 |
| `data/traits.json` | ジョブ特性を覚えるレベル (サポートジョブの特性に使う) |
| `data/foods.json` | 食事の効果 |
| `data/caps.json` | ステータスの上限 |
| `data/sources/*.json` | どの装備がどのコンテンツで手に入るか (Wiki から集めた一覧) |
| `data/contents.json` | 設定画面の「コンテンツごとの装備」の行の定義 |
| `data/battlefields.json` | 上位ミッションBF の日本語名 |
| `tools/ui-check.sh` | 実際の画面をヘッドレスの Edge で開いて確かめる (開発用) |
| `CLAUDE.md`, `.claude/agents/` | Claude Code 向けの決まりと、下位モデルに回す作業の定義 |
| `mock/tp.html` | 得TP・振り数の画面のモック |
| `mock/index.html`, `mock/settings.html` | 画面を作ったときのモック (見た目だけ) |
